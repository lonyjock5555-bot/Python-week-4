
# PLP Week 4 Python Assignment

## Project Description

This project is part of my Power Learn Project (PLP)
Python Week 4 assignment.

The project demonstrates how to create and use Python
functions, parameters, return statements, and default
parameters.

## Files

### welcome.py

This file contains a welcome function that greets users
by their name.

### toolbox.py

This file contains reusable Python functions for:

- Doubling numbers
- Checking whether a student passed
- Creating greeting messages

## Skills Learned

- Creating Python functions
- Using parameters
- Using return statements
- Working with default parameters
- Testing Python functions
- Writing clean and reusable code
